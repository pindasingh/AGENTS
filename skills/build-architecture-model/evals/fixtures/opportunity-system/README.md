# Synthetic cross-repository evaluation fixture

Treat each immediate child directory as a separate supplied repository at a fixed synthetic revision. The successful Search Opportunities operation has two corroborated callers and continues through Search API, Eligibility API, and Details API. The handler also touches LaunchDarkly, local bound configuration, Elasticsearch, SQL, and Application Insights in the displayed order.

This fixture intentionally contains no message bus. Agents must not add one. Local `options.Value` is not a remote configuration runtime.
